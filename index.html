KASIR / PERANGKAT

Setting Printer INFORCE P58C

Mode Android Bluetooth langsung dan Windows melalui dialog cetak / driver.

Pengaturan perangkat ini
P58C menggunakan kertas thermal 58 mm.
Android: Bluetooth ESC/POS Bridge
Windows: Driver / Print Dialog
Metode dipilih otomatis berdasarkan perangkat yang membuka aplikasi.

Android memerlukan Cleanter aktif dan printer sudah dipilih. Windows menggunakan driver printer dan dialog cetak.

1. Android — Cetak Bluetooth Langsung

Aplikasi ini disiapkan untuk mengirim struk ESC/POS ke layanan Cleanter pada perangkat Android yang sama. Browser tidak dapat mengakses Bluetooth Classic SPP secara langsung tanpa aplikasi penghubung.

  1. Pasangkan INFORCE P58C dari Pengaturan Android → Bluetooth. PIN sesuai manual printer (sering 0000 atau 1234).
  2. Instal Cleanter — Thermal Printer BT.
  3. Buka Cleanter, pilih printer INFORCE P58C sebagai printer default, lalu tekan Start / aktifkan server.
  4. Pastikan aplikasi kasir dan Cleanter berjalan pada HP Android yang sama.
  5. Kembali ke aplikasi POS, lakukan transaksi lalu tekan Cetak Struk. Aplikasi akan mengirim data langsung ke printer tanpa dialog browser.

Koneksi bridge lokal: http://localhost:9100. Status bridge dan printer diperiksa saat proses cetak. Cleanter versi 1.1.0 atau lebih baru diperlukan untuk aplikasi POS yang dibuka melalui HTTPS.

2. Windows — Cetak melalui Driver

Pada Windows, tombol Cetak Struk membuka dialog cetak browser. Pilih printer INFORCE yang sudah terpasang. Untuk P58C, prioritaskan koneksi USB dan instal driver yang sesuai dengan varian printer. Bluetooth Classic tidak dapat dikendalikan langsung oleh Chrome hanya dengan pairing.

  1. Sambungkan printer ke Windows menggunakan kabel USB (atau ikuti petunjuk driver resmi untuk varian unit Anda).
  2. Unduh driver dari halaman Driver resmi INFORCE. Pastikan paket driver memang untuk P58C / P58C-NB sebelum instalasi.
  3. Buka Windows Settings → Bluetooth & devices → Printers & scanners. Pastikan printer terdaftar.
  4. Tekan Test Print, pilih INFORCE P58C, ukuran kertas 58 mm, dan matikan header/footer browser jika tersedia.
  5. Saat mencetak struk transaksi, pilih printer yang sama pada dialog cetak.

Jika printer hanya dipasangkan melalui Bluetooth dan tidak muncul sebagai printer Windows, gunakan koneksi USB atau driver/port COM resmi yang disediakan untuk varian tersebut.
